# Playbook — Founder Capture

- **Card id:** `biz-founder-capture`
- **Human owner:** `founder`
- **Primary artifact:** `capture-packet.md`
- **Done when:** Packet has structured sections + suggested lanes; no silent drop of founder items

## Intent triggers

`voice note`, `capture`, `brain dump`, `telegram dump`, `messy idea`

## Skills to load

- `audio-producer`
- `content-lifecycle-os`
- `todo-discipline`
- `starlight-work-ledger`

## Inputs

- transcript or chat paste
- optional audio path

## Steps

1. Ingest raw founder signal without rewriting identity
2. Split into: tasks, offers, content seeds, SOP candidates, decisions needed
3. Tag each item with suggested specialist lane
4. Write capture-packet.md + optional task stubs for Delegation
5. Hand off TOP items to CoS / Content / Delegation
