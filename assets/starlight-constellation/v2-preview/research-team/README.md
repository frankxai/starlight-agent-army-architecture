# Research Team character direction pilot

This folder is a non-production design review space for the Starlight Research Team. It begins with Lyra because the conductor role provides the clearest test of role-shaped morphology and swarm handoffs.

- `prompts/` contains reproducible image-job receipts.
- `candidates/` contains repository-owned generated exports after inspection.
- `selection-receipt.v1.json` compares the inspected set and recommends a human-reviewed blend with Precision Instrument v2 as the governance-correct base.
- `design-loop-evidence.json` records the premium asset gate, known failures, and why this remains an iteration rather than a ship decision.

Nothing in `v2-preview` replaces the current v1 production portraits. Human identity approval and downstream site QA remain required.
